# 📞 Call Center Performance Analysis 2023

## 📝 Overview
This repository contains an end-to-end data analysis project focusing on a regional call center's performance for the Fiscal Year 2024. Using a dataset of 1,000 individual calls, this project evaluates key operational metrics, including call volume trends, customer satisfaction, demographic behaviors, and representative efficiency. The centerpiece of this project is a highly interactive Excel dashboard designed to help management optimize staffing and enhance the overall customer experience.

## ✨ Key Features
- **Dynamic Interactivity:** A fully functional dashboard controlled by agent-specific slicers, allowing for granular performance reviews of individual representatives (R01 - R05).
- **Comprehensive KPI Tracking:** High-level metrics tracking total calls, total revenue generated ($96K+), average call duration, and overall customer satisfaction.
- **Trend Analysis:** Visualizations mapping monthly call volume fluctuations and daily operational peaks.
- **Demographic Insights:** Breakdown of caller demographics (Male vs. Female) across key operational cities (Cincinnati, Cleveland, and Columbus).
- **Agent Efficiency Mapping:** Direct comparison of total calls handled versus total purchase amount generated per representative.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel:** Primary tool for data manipulation, analysis, and visualization.
- **Pivot Tables & Pivot Charts:** Used extensively to aggregate data and feed the dynamic dashboard.
- **Data Modeling:** Connecting multiple pivot tables to a unified slicer for seamless filtering.
- **Data Cleaning & Formatting:** Ensuring raw data was structured correctly for accurate analysis.
- **Dashboard UI/UX Design:** Creating a clean, professional, and intuitive interface for business users.

## 🧠 Skills Demonstrated
- **Business Intelligence (BI) & Reporting:** Translating raw datasets into actionable business insights.
- **Data Storytelling:** Presenting complex data in a visually digestible format.
- **KPI Development:** Identifying and highlighting the metrics that matter most to call center management.
- **Problem Solving:** Addressing specific business questions through targeted data analysis.
